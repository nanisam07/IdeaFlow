# IdeaFlow


**Turn Data Into Decisions**

IdeaFlow is a modern SaaS analytics dashboard designed to help businesses monitor performance, track growth, and make data-driven decisions through intuitive visualizations and real-time insights.

Built with React, TypeScript, Tailwind CSS, and modern frontend technologies, IdeaFlow demonstrates enterprise-grade dashboard design and user experience.

## 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/nanisam07/IdeaFlow.git
cd ideaflow
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

### Build Project

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```
